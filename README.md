# Interview Helper

一个面向技术候选人的开源 AI 模拟面试应用。产品根据目标公司、面试轮次、岗位方向、个人题库和简历，组织连续追问，并在结束后提供基于真实回答证据的评估。

当前项目处于规格与实施准备阶段，尚未开始业务代码开发。
