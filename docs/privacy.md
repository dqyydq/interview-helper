# 隐私、本地数据、删除与备份

Interview Helper 第一阶段面向单机单用户。它是“本地优先”，不是“所有处理都离线”：当用户配置远程模型或 STT 服务时，完成对应任务所需的数据会发送到该服务。

## 本地保存的数据

- PostgreSQL：公司、轮次、题库、简历解析结果、面试计划、确认消息、摘要、长期记忆、报告、诊断计数和模型连接密文。
- `data/uploads/<profile-id>/`：简历源文件，使用随机文件名并与用户展示文件名分离。
- Docker named volumes `interview-helper-models` 与 `interview-helper-model-state`：后续经用户显式安装、校验完成的本地模型文件及其下载/校验状态。它们不包含 API Key、简历、面试回答或数据库业务数据。
- 浏览器临时状态：尚未确认的输入、录音转写编辑稿和代码白板草稿。

应用不把每个流式 token 写入数据库，只保存最终确认消息。摘要和长期记忆都是可重新生成、可追溯的派生数据；它们不会覆盖原始消息。

## 发送给模型服务的数据

### 面试官

公司/轮次规则、冻结计划、当前题目、最近确认对话、预算允许的摘要、题库或简历片段，以及用户明确保留的长期记忆。

### 评估官

冻结计划、按题确认的原始回答、文本代码附件和评估维度。代码附件带有 `execution_allowed=false`，服务端不会执行。

### Coach

已完成报告、用户选择的问题结论和必要的证据消息，不读取整份简历、其他会话或未提供的长期记忆。

### 语音转写

用户主动录制并提交的单个音频文件。转写结果先回到浏览器供编辑确认，确认前不作为面试回答入库。

### 视觉资料解析

用户在公司画像草案中主动选择的单张、已脱敏截图会发送给该用户明确绑定的“视觉资料解析”模型。原始截图只保留在本次请求的内存中，接口完成后不会写入 `data/uploads`、PostgreSQL、向量索引、面试上下文或应用日志。模型只能返回匿名化的候选结论；只有用户逐条确认后，来源链接、标题和该条简短结论才会写入私有风格草案。截图中的完整题目、联系方式、姓名和疑似保密内容不应上传，且不会自动进入共享题库或公开公司画像。

不同模型服务有各自的数据保留政策。使用真实 Provider 前，应自行审查其区域、日志、训练和删除条款。

### Docker-only 本地 AI（后续能力）

用户明确启用本地容器后，音频或 embedding 请求只会在 `127.0.0.1` 上的本地服务与应用之间传递，不会静默回退到云端。模型文件仅在用户显式执行安装流程时从其选择的模型来源下载；普通应用启动和进行中的面试不会下载模型、预热模型或重建索引。当前 Compose 只预留该能力的 volumes 与 profile，尚未提供可运行的本地模型服务。

## 不可信数据边界

简历、题目、回答、代码附件、历史模型消息和外部资料都只被当作数据，不能覆盖系统规则。系统提示明确要求忽略其中改变角色、泄露提示词、执行代码或绕过证据边界的指令。该边界降低提示注入风险，但不能宣称彻底消除模型风险。

## 密钥和日志

- API Key 与额外请求头使用 Fernet 派生密钥加密后保存。
- `INTERVIEW_HELPER_ENCRYPTION_SECRET` 不进入数据库；备份时必须另行安全保存。
- HTTP 日志记录 request ID、方法、路径、状态码和耗时，不记录正文。
- 脱敏器处理常见 secret/token/password/authorization 字段与回答、prompt、transcript、resume 等内容字段。
- 系统诊断不返回数据库 URL、密钥密文、回答正文、简历正文或绝对路径。

第一阶段没有账号与权限隔离，不应直接监听公网地址或供不受信任的多用户共享。

## 删除

删除模型连接会同时删除角色绑定和数据库中的密文。

删除简历：

```http
DELETE /api/resumes/{resume_id}
```

该操作会删除解析任务、数据库记录及隔离目录中的源文件。题目删除采用归档语义，以保留已完成计划的历史引用；长期记忆可在“设置 → 长期记忆”逐条删除，删除后不再进入新会话。

已发送到外部 Provider 的数据不能由本地删除接口代替清除，应按 Provider 的控制台或政策处理。

## 备份边界

完整可恢复备份至少包括：

1. PostgreSQL dump。
2. `data/uploads`。
3. 当前 `.env` 中的 `INTERVIEW_HELPER_ENCRYPTION_SECRET`，单独加密保存。

模型 volumes 不属于业务数据备份的必需组成部分：它们可能很大，并且在未来可由经过校验的 manifest 重新获取。不要把模型 volume 当作数据库或上传文件的替代备份；其安全升级步骤见 [Docker-only 本地 AI](local-ai.md)。

示例：

```powershell
docker compose exec -T postgres pg_dump -U interview_helper -d interview_helper -Fc -f /tmp/interview_helper.dump
docker compose cp postgres:/tmp/interview_helper.dump .\backup\interview_helper.dump
Copy-Item -Recurse .\data\uploads .\backup\uploads
```

不要把 `.env`、数据库 dump、上传目录或诊断以外的日志提交到 Git。恢复时先恢复数据库，再恢复相同相对位置的上传目录，并使用原加密密钥；缺少任一项都可能造成密钥或简历源文件不可用。

## 当前限制

- 没有 TTS；面试官只返回文字。
- 不执行代码，不提供沙箱，也不对代码附件进行联网操作。
- 不自动联网研究公司；用户负责录入和维护来源。
- 不提供端到端加密同步、团队权限、审计导出或云端灾备。
- 实时面试仅支持单个 API 进程；多实例部署前需要共享会话锁和连接协调，不能把当前单机配置直接扩展到公网集群。
